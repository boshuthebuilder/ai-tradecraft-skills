# pre-onboarding tools

The tools [`pre-onboarding`](../SKILL.md) runs: standard-library Python (3.9+) plus one Swift helper for Apple
Vision OCR, generic and settings-driven. Every command, flag, output and exit code, the charts' rules included, is
in the tool reference, [`../references/tools.md`](../references/tools.md); the settings twins' formats are in
[`../references/settings.md`](../references/settings.md), and the card contract in
[`../references/cards.md`](../references/cards.md).
